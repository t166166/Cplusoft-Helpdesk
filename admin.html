🚀 Power Automate Setup Guide (Step-by-Step)

⚠️ Yeh ek-baar setup hai. SharePoint list banao, phir teen flows banao. Har flow ka URL yahan paste karo.

📋 Step 1 — SharePoint List

1
SharePoint site kholo → New → List → Name: HelpDeskTickets
2
Yeh columns banao (single line of text unless noted):
TicketID, SubmitterName, SubmitterEmail, Department, Category, Priority, Subject, Description (multi-line), Status, SLAMinutes (number), Deadline, ResolvedAt, ResolvedAtTS (number), TimeTakenMinutes (number), SLAMet (yes/no), Timeline (multi-line), CreatedAtTS (number)

⚡ Step 2 — Flow 1: Create Ticket

1
Power Automate → Create → Instant cloud flow → Trigger: "When an HTTP request is received"
2
JSON Schema field mein neeche wala schema paste karo → Save
3
Action add karo: SharePoint → Create item → Site: aapki SharePoint URL → List: HelpDeskTickets → Har field mein dynamic content se match karo
4
Action add karo: Office 365 Outlook → Send an email (V2):
From: m.basit_cplusoft@outlook.com
To: @{triggerBody()?['email']}
Subject: [Ticket @{triggerBody()?['id']}] Received
Body: neeche wala Email Body Template use karo
5
Save → HTTP POST URL copy karo → yahan "Create Ticket URL" mein paste karo

⚡ Step 3 — Flow 2: Resolve Ticket

1
Naya Instant flow → HTTP trigger
2
Action: SharePoint → Get items → Filter: TicketID eq '@{triggerBody()?['id']}'
3
Action: SharePoint → Update item → ID: @{first(body('Get_items')?['value'])?['ID']} → update karo: Status = Resolved, ResolvedAt, ResolvedAtTS (= @{triggerBody()?['resolvedAtTS']} — number, isi se dashboard "Time Taken" sahi dikhata hai), TimeTakenMinutes, SLAMet, aur Timeline (= @{triggerBody()?['timeline']} — taake resolve ki entry bhi history mein save ho)
4
Action: Outlook → Send email → Resolution email user ko
5
HTTP URL copy → "Resolve Ticket URL" mein paste karo

⚡ Step 4 — Flow 3: Get Tickets

1
Naya Instant flow → HTTP trigger
2
Action: SharePoint → Get items → List: HelpDeskTickets → Top: 500
3
Action: Response → Status: 200 → Body: @{body('Get_items')} → Content-Type: application/json
4
HTTP URL copy → "Get Tickets URL" mein paste karo
